Enumerations
============

ShipType_t (uint32_t):
    1 = Corvette
    2 = Frigate
    3 = Destroyer
    4 = Light Cruiser
    5 = Heavy Cruiser
    6 = Battleship

OffRank_t (uint32_t):
    0 = N/A
    1 = Ensign
    2 = Sub-Lieutenant
    3 = Lieutenant
    4 = Sub-Commander
    5 = Commander
    6 = Captain

ShipDept_t (uint32_t):
    1 = Command
    2 = Operations
    3 = Engineering
    4 = Navigation
    5 = Weapons









File Structure:
===============

[File Header]
- Magic number/version
- Page size (4096)
- Root page IDs for system catalogs
- Next available page ID

[System Catalog Pages]
- Table: sys_tables (table_id, table_name, record_size, root_page_id)
- Table: sys_columns (table_id, column_name, offset, type, size, constraints)
- Table: sys_indexes (index_id, table_id, column_name, root_page_id)
- Table: sys_enums (enum_name, value, label)

[Data Pages]
- Your actual Ship, Officer, etc. tables
- B+ tree index pages
